# Python Data Analysis
本仓库用于数据分析学习，涵盖 Numpy、Pandas、Matplotlib、数据清洗与可视化。
使用教材《Python for Data Analysis》（第三版）。

## 内容结构
- numpy/：矩阵操作、广播机制、随机数
- pandas_basic/：Series 与 DataFrame 操作
- pandas_advanced/：分组、透视表、缺失值处理
- matplotlib/：折线图、柱状图、散点图、子图
- projects/：小型数据分析项目

## 数据项目示例
- 学生成绩分析
- 图书销量数据清洗
- 城市空气质量数据可视化
